整合包是 1.20.1 真正强项。乌托邦探险之旅 3.0 就是为 1.20.1 开发的 Fabric 整合包，505 个模组。大量社区整合包把 1.20.1 当作基准版本，你搜到的玩法包、科技包、魔法包，大概率也是这个版本。

官方生态也依然覆盖 1.20.1。网易《我的世界》中国版 JAVA 网络游戏入驻页面写明“目前官方支持的版本有 1.7.10 - 1.20.1”，入驻到上架不收费用也不收押金，一审通过后免费发一台正式机（性能较差，可以再申请低频正式机或付费租赁物理机），机器默认开放 25566/25565 端口。

还有一个容易忽略的坑：客户端必须跟服务端同版本。1.20.1 的客户端连不上其他分支的服务端，除非服务端装了 ViaVersion。有些服只收 1.20.1，有些通过 ViaVersion 收整个 1.20 分支，进服前问清楚。

## 配置怎么定

### CPU：单核性能第一

Java 版从 1.18 之后对单核性能的要求明显提高。一个 2026 年 8 月的开服教程给出的判断标准是 CPU-Z 单核跑分 600 分以上，14900K、13900K、7950X、9950X 都是经过验证的选择。

这条标准对 1.20.1 特别适用。1.20.1 的主线程压力集中在地图生成、实体 AI 和区块加载上，核多并不能补上单核不足的问题。一台 8 核但单核弱的机器，实际表现经常不如 4 核高频机。

面板服的 5 种机型里，Platinum 8275cl、Gold 6146、E5 2666V3 都是服务器 CPU，核心多但主频低，它们适合当 VPS 跑多服务，不适合当 1.20.1 服的主力。这就是教程作者反复推荐 14900KF 和 5900X 的原因。

### 内存：4 核 8G 是下限，不是目标

两份独立的教程说法一致：配置建议 4 核 10G 及以上，最低不要低于 4 核 8G。原版和 SMP 服 4 核 8G 够用，整合包服要往上加。

内存不够的表现很典型。服务端启动时卡在加载模组，或者跑了一段时间后 TPS 掉到个位数，日志里开始刷 GC 相关的警告。整合包玩家这边则是“玩着玩着闪退”，本质是系统、浏览器、语音软件和应用抢内存，最终把 Java 进程杀掉了。

客户端那条经验值可以拿来参考：分配量不要超过电脑物理内存的 50%，16G 的机器最多给 8G。判断够不够看 F3 右上角的 Allocated Memory 和 Used Memory，长期超过 80% 说明给少了，长期低于 30% 说明给多了。服务端没有 F3，看面板的内存曲线和日志里的 GC 频率，思路一样。

预算卡在 4 核 8G 又想跑整合包，可以先上 8G 跑起来，人多了或者卡了再在面板里加内存，雨云支持随时升降配置。

### Java 版本：公开教程有两种说法

1.20.1 该装哪个 JDK，公开资料里同时存在两种说法。

一份 2026 年 8 月的雨云论坛开服教程给了张通用对照表：JDK 17 对应 1.17–1.19，JDK 21 对应 1.20 及以上。另一份讲整合包联机的攻略写的是 MC 1.18 及以上用 Java 17。落到 1.20.1 上，两边的答案不一样。

实操上跟服务端或整合包作者的要求走。乌托邦探险之旅 3.0 是 1.20.1 的 Fabric 包，作者在服务端压缩包里直接塞了 Windows 版 JDK 17，客户端也配了 JDK 17，下载下来双击 bat 就能跑。雨云面板服这边，购买时游戏类型选“纯 Java 环境”之后可以选 Java 21 作为运行环境。

所以顺序是：先看整合包压缩包里有没有自带运行时，有就用它的；没有就翻作者的说明文档；两者都没有，按通用对照表装 JDK 21，起不来就换成 17。Java 版本装错的典型表现是启动即报 `UnsupportedClassVersionError`，服务端连主界面都进不去，换一个 JDK 就好。

### 磁盘：SSD 预留 20G 以上

整合包的磁盘占用经常被低估。游戏目录本体（JAR、配置、资源）约 5–8G，核心模组和运行时约 1G，存档跑图半径一大轻松破 5G，高清材质单包就可能 10–20G。SSD 上建议预留 20G 以上。

硬盘常年红条不只是存不下，加载速度会断崖式下降，连带影响区块加载，玩家跑图时能明显感觉到卡顿。

## MCSM 面板服与游戏云 VPS 的选择

一句话判断：只想要一个能玩的 1.20.1 服，选面板服；想自己掌控整台机器、同时跑别的服务、或者需要 NAT 端口自由度，选 VPS。

### MCSM 面板服：省事的路径

流程节点是这样的：购买时游戏类型选“纯 Java 环境”，选好机型和配置，付款后进控制台拿到面板地址和端口。进面板，文件管理里上传整合包服务端压缩包（解压时编码选 GBK），解压后把文件全选复制到根目录。

接下来两处必须改。

`server.properties` 里的 `server-port=25565` 要改成面板分配给你的那个端口，比如示例里的 29183。这一步漏了，服务端起来了但没人连得上，因为面板服走的是端口映射，不是标准 25565。同一个文件里的 `online-mode` 决定是否开启正版验证。

启动脚本 `启动脚本(可修改).sh` 里的命令改成 `java -Xms128M -XX:MaxRAMPercentage=95.0 -jar server.jar`。`MaxRAMPercentage=95.0` 的意思是 JVM 最多用掉系统内存的 95%，剩下的留给系统。

然后回控制台点开启实例，等日志刷出启动完成。客户端多人游戏里“添加服务器”，填控制台显示的地址加端口，格式是 `地址:端口`，比如 `um.rainplay.cn:29183`。

`online-mode=false` 的代价要提前想清楚。关掉正版验证之后所有人都能进你的服，被 ban 了换个 ID 还能回来。小圈子内部玩无所谓，公开服千万别关。

### 游戏云 VPS：自由度换折腾时间

VPS 拿到的是完整系统权限，装 MCSManager + Docker 自己搭。流程比面板服长：先做 NAT 端口映射，再 SSH 登录，换 apt 源，跑脚本装 MCSM（Docker 版），新建节点填 Daemon 密钥，装 JDK，新建实例选对应镜像，上传 `server.jar`，开放端口，最后开启。

端口映射是 NAT 机型的关键一步。MCSM 面板自己占 23333 和 24444 两个端口，Minecraft 服务端默认 25565，三个都要在雨云控制台的 NAT 端口映射里建规则，协议选 TCP+UDP。镇江 NAT 机型提供 15 个端口，外网端口范围 10000–60000，如果提示外网端口已被使用就自己换一个。

区域选择有取舍。镇江是 NAT 网络（多用户共用公网 IP，可以加钱选独立公网 IP），镇江和宿迁都是 BGP 线路，各运营商延迟都低。宁波有便宜的独立公网 IP，但是电信单线，高峰期其他运营商用户延迟会明显升高。

启动命令示例：`java -Xms1G -XX:MaxRAMPercentage=90.0 -XX:+UseZGC -jar server.jar nogui`。`-XX:+UseZGC` 启用 ZGC 垃圾回收器，适合 MC 这种需要长时间稳定运行的服务端，能减少卡顿；这个参数只有 JDK 15 及以上才正式支持，低版本要去掉。

第一次启动会提示 `You need to agree to the EULA in order to run the server`，编辑 `eula.txt` 把 eula 改成 true。Docker 实例还要在“容器化 → 开放端口”里把 25565 的 TCP 放出去，否则容器内的服务端外面连不到。

## 1.20.1 整合包服最常见的三个问题

### 版本链没对齐

原版服只要版本号对上就行。整合包要对齐的是一串：游戏主版本（1.20.1）、模组加载器及版本（Forge 47.2.0 / Fabric 0.15.11）、MOD 列表与每个 MOD 的版本、config 目录和脚本改动。差一个都不行。

最常见的报错是 Mod Rejection，后面跟一长串不匹配的模组名。看到这个基本可以断定 MOD 列表或版本没对齐。

### 各自安装各自的模组

整合包一定要整包分发。用启动器导出整合包，或者干脆打个压缩包发群里，所有人解压即用。手动一个个装 MOD，十次有九次会漏。服务端那份文件也必须是同一份，不要在服务端手动加客户端模组，反过来也一样。

### 内存给多了或给少了

整合包的参考 JVM 参数：`-Xmx6G -Xms6G -XX:+UseG1GC -XX:MaxGCPauseMillis=200`。最大和初始内存都设 6G 避免运行中频繁扩容，启用 G1 回收器，单次回收暂停控制在 200 毫秒内。物理内存 16G 的机器给 6G 比较稳妥，32G 可以给到 8G。

给多了和给少了一样会出问题。给到 12G 的话系统、浏览器、语音软件没得用，反过来会把 Java 进程杀掉。

## FAQ

**1.20.1 到底用 Java 几？**

公开教程有 JDK 21（通用对照表口径，1.20 及以上）和 JDK 17（整合包攻略口径，1.18 及以上）两种说法。以整合包作者要求为准，乌托邦 3.0 随包提供的就是 JDK 17。

**4 核 8G 够几个人？**

原版和 SMP 服 3–8 人没问题。整合包服 4 核 8G 是下限，10 人以上或者跑 500 模组级别的包，按 4 核 10G 配。

**面板服和 VPS 差在哪？**

面板服给的是网页面板，开机即用，上传整合包、改配置、看日志都在浏览器里完成，但没有系统级权限。VPS 给完整系统权限，能 SSH、能装 Docker、能跑多个服务，代价是首次部署要花时间。

**关掉正版验证有什么风险？**

`online-mode=false` 之后所有人都能进服，被 ban 了换个 ID 还能回来。内网小圈子玩可以接受，公开服不建议。

**动态计费和固定计费怎么选？**

不常玩的选动态计费，逻辑是 CPU 占用率超过 20% 时才额外计费，每天有免费额度；经常开着的选固定计费更省心。

**退款和试用什么政策？**

雨云官方退款政策页面（2024 年 6 月修订）写的是七天无理由退款，每位用户 3 次机会，在具体产品的控制面板点退订自助操作。有几个例外：领取产品消费积分后、1 元试用后续费后、超过 7 天，都不能退订；日付、流量包、游戏云电量、IP 增加、硬盘或套餐升级这类非月付场景不支持退订。下单前把这些条款自己读一遍。
